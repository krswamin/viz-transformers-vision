This repo contains 
- Implementations of Various Transformer Architectures for Visions
- Experiments with associated concepts such as attention mechanisms, layer norm etc. 
- Broadly Vizuara MOOC Course: Transformers for Vision lectures by Dr. Sreedat Panath is the guidelines for the code.
   - Original code released by Vizuare is included
   - But original implementations and experimentations from scratch is goal of this repo
- Most code is in jupyter notebooks, for easy experiments  and adding visual comments and diagrams
